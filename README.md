# FireScout

Autonomous indoor scout robot for firefighters, built for the AgentVerse 2026 Robotics track (MuJoCo simulation).

FireScout is placed at the doorway of a smoke-filled building. While the crew puts on breathing apparatus, it explores using a simulated thermal camera and mmWave radar, pins casualties with a confidence score, replans live around fire with a visible reason for every decision, and hands the Incident Commander a rescue route, an exit route and a METHANE report. All decisions run on-device.
